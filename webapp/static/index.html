1. ปัญหาภาพจริง (Problem)

ทำไม Bicubic ถึงขยายแล้วเบลอ?

ภาพจริงมีความเสื่อมสภาพปนกันหลายแบบ ทั้งภาพสั่น (Blur), สัญญาณรบกวน (Noise) และรอยแตก JPEG การขยายด้วย Bicubic เป็นเพียงการเฉลี่ยค่าพิกเซลเดิม จึงยิ่งทำให้ภาพเบลอมัวและขอบแตก

2. แนวทางของทีม (Solution)

2-Stage Degradation + RRDBNet

จำลองความเสื่อมสภาพซ้อน 2 ชั้นระหว่างฝึก เพื่อให้ RRDBNet (23 บล็อก) และ U-Net Discriminator เรียนรู้การกู้คืนพื้นผิวและขอบเส้นจริง พร้อมจัดการหน่วยความจำให้รันบนการ์ดจอ 4GB ได้

วิธีวัดคุณภาพภาพ Super-Resolution

ไม่มีตัวเลขตัวเดียวที่บอกคุณภาพได้ครบ จึงต้องใช้ตัวชี้วัดหลายมิติร่วมกัน ทั้งความถูกต้องพิกเซล ความสวยตามสายตา และความเร็ว

💡 สรุปสั้น (TL;DR)
ดูคู่กัน 4 ด้าน: 1) ตรงต้นฉบับ (PSNR, SSIM ยิ่งสูงยิ่งตรง) · 2) สวยถูกใจคนดู (LPIPS ยิ่งต่ำยิ่งดี, MUSIQ ยิ่งสูงยิ่งดี) · 3) เป็นธรรมชาติไร้รอยแตก (NIQE ยิ่งต่ำยิ่งดี) · 4) ใช้งานจริงไว (Latency ยิ่งต่ำยิ่งไว)
📐
📏 ความแม่นยำพิกเซล
PSNR ↑ ยิ่งสูงยิ่งดี
Peak Signal-to-Noise Ratio
หน่วย: dB (Decibel) · ใช้ภาพเทียบ (Full-Reference)

วัดความคลาดเคลื่อนระดับพิกเซล (MSE) เทียบกับภาพต้นฉบับ ยิ่งสูงแปลว่าสีและแสงใกล้เคียงต้นฉบับ แต่มักไม่สะท้อนความคมชัดของลวดลายละเอียด

PSNR = 10 · log₁₀(MAX² / MSE)
🏗️
📏 ความแม่นยำโครงสร้าง
SSIM ↑ ยิ่งสูงยิ่งดี
Structural Similarity Index Measure
ช่วงคะแนน: 0.0 – 1.0 · ใช้ภาพเทียบ

วัดความคล้ายคลึงด้าน ความสว่าง, ความเปรียบต่าง และโครงสร้างวัตถุ ใกล้เคียงการมองเห็นของมนุษย์มากกว่า PSNR ยิ่งเข้าใกล้ 1 ยิ่งดี

SSIM = f(luminance, contrast, structure)
👁️
👁️ สายตามนุษย์ (Perceptual)
LPIPS ↓ ยิ่งต่ำยิ่งดี
Learned Perceptual Image Patch Similarity
ช่วงคะแนน: 0.0 – 1.0 · ใช้ Deep Features เทียบ

วัดระยะห่างของลักษณะภาพจาก Deep Neural Network เพื่อจำลองสายตามนุษย์ ยิ่งต่ำแปลว่าภาพดูคมชัดและสมจริงในสายตาคนดู

LPIPS = ‖φ(x̂) − φ(x)‖₂²
🌿
🌿 ความเป็นธรรมชาติ
NIQE ↓ ยิ่งต่ำยิ่งดี
Natural Image Quality Evaluator
No-Reference (ไม่ต้องมีภาพต้นฉบับเทียบ)

เปรียบเทียบสถิติของภาพกับสถิติภาพถ่ายธรรมชาติ ยิ่งต่ำยิ่งแสดงว่าภาพเป็นธรรมชาติ ไม่มี Noise แปลกปลอมหรือขอบเรืองแสงหลอกตา

NIQE = D(v_test, v_natural)
🌟
👁️ ความสวยงามหลายสเกล
MUSIQ ↑ ยิ่งสูงยิ่งดี
Multi-scale Image Quality Transformer
คะแนน 0 – 100 · No-Reference

ใช้โมเดล Vision Transformer ประเมินความสวยงามและความคมชัดแบบหลายสเกล เหมาะกับภาพจริงที่ไม่มีต้นฉบับ ยิ่งคะแนนสูงยิ่งคมชัดสวยงาม

MUSIQ Score ∈ [0, 100]
⏱️
⚡ ความเร็วใช้งานจริง
Latency ↓ ยิ่งต่ำยิ่งไว
Processing Time per Image
หน่วย: ms (มิลลิวินาที) · RTX 3050 Ti GPU

เวลาที่โมเดลใช้ขยายภาพ 1 ใบ บนการ์ดจอเดียวกันทั้งหมด วัดเพื่อพิสูจน์ว่าโมเดลสามารถนำไปใช้งานจริงได้อย่างรวดเร็ว

Latency = t_end − t_start (ms/image)
💬 ทำไมต้องดูหลายตัวชี้วัดพร้อมกัน? (Perception–Distortion Tradeoff)
🎯
PSNR / SSIM สูงอย่างเดียวอาจยังเบลอ: โมเดลที่ใช้ L1 Loss (เช่น Real-ESRNet) มักได้ PSNR สูงเพราะทำค่าเฉลี่ยพิกเซลได้ดี แต่ภาพอาจดูเรียบแบนขาดรายละเอียดพื้นผิว
🧠
LPIPS / NIQE / MUSIQ ช่วยวัดความคมชัดจริง: เมื่อใช้ GAN ร่วมด้วย ภาพจะมีรายละเอียดเส้นขน ใบไม้ และพื้นผิวที่สมจริงมากขึ้น ทำให้ LPIPS และ NIQE ดีขึ้นอย่างชัดเจน
⚖️
เป้าหมายของทีม: รักษาความสมดุลให้ได้ทั้งความคมชัด (LPIPS/NIQE ดีที่สุด) และยังคงความถูกต้องของพิกเซลสูงกว่าโมเดลทางการ (PSNR/SSIM ชนะ Official)

🔍 เปรียบเทียบสถาปัตยกรรม Discriminator: VGG vs U-Net + Spectral Norm
❌ VGG-style Discriminator (แบบเดิม)
  • บีบเหลือค่าเดียว: ตัดสินภาพจากการลดขนาดจนเหลือตัวเลข Scalar ค่าเดียว (Global Context)
  • มองไม่เห็นจุดเล็กๆ: ไม่สามารถชี้ตำแหน่งพิกเซลที่เพี้ยนได้ ทำให้เกิด Noise และลายหลอนง่าย (LPIPS 0.2980)
✅ U-Net Discriminator + Spectral Norm (ที่ใช้ในระบบนี้)
  • ประเมินระดับพิกเซล: มี Encoder-Decoder + Skip Connections ช่วยให้ตรวจจับทั้งโครงสร้างรวมและพื้นผิวเฉพาะจุด
  • Spectral Norm (SN): คุมขอบเขต Gradient ไม่ให้แกว่งรุนแรงระหว่างฝึก ทำให้ภาพคมชัดเป็นธรรมชาติ
