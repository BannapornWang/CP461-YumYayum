❓ ปัญหา (The Problem)

ทำไม Bicubic ไม่เพียงพอ?

ภาพถ่ายในโลกจริงมีความเสื่อมสภาพจากหลายแหล่งพร้อมกัน ทั้งการสั่นไหวของกล้อง (Motion Blur), สัญญาณรบกวนจากเซนเซอร์ (Sensor Noise), การบีบอัด JPEG (Compression Artifact) และความละเอียดต่ำจากระยะห่าง — Bicubic Interpolation ขยายภาพโดยการประมาณค่าระหว่างพิกเซล ทำให้ภาพเบลอมัวและสูญเสียรายละเอียด ไม่สามารถสร้างเนื้อหาใหม่ได้

📷 Blur & Camera Shake ⚡ Sensor Noise 🗜️ JPEG Artifacts 🔍 Resolution Loss
💡 แนวทางแก้ไข (Our Approach)

Two-Stage Degradation + RRDBNet

Real-ESRNet ฝึกให้โมเดลเรียนรู้การกู้คืนภาพจากความเสื่อมสภาพสังเคราะห์ที่ซับซ้อน ด้วยกระบวนการ High-Order Degradation 2 ชั้น เพื่อให้โมเดลทนทานต่อภาพจริงที่มีความเสื่อมสภาพหลายรูปแบบพร้อมกัน และสามารถสร้างรายละเอียดภาพใหม่ที่คมชัดได้

📊 ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)

วิธีวัดคุณภาพ Super-Resolution

งานวิจัยด้าน Image Restoration ใช้ตัวชี้วัดหลายมิติพร้อมกัน เพราะตัวชี้วัดแต่ละตัวสะท้อนมุมมองที่แตกต่างกัน

📐
PSNR ↑ สูงดีกว่า
Peak Signal-to-Noise Ratio
หน่วย: dB (Decibel)

วัดอัตราส่วนระหว่างสัญญาณภาพสูงสุดกับสัญญาณรบกวน โดยคำนวณจาก Mean Squared Error (MSE) ระหว่างภาพทำนายกับภาพต้นฉบับ ยิ่งสูงยิ่งหมายความว่าภาพใกล้เคียงต้นฉบับมากขึ้น

PSNR = 10 · log₁₀(MAX² / MSE)
🏗️
SSIM ↑ สูงดีกว่า
Structural Similarity Index Measure
ช่วงค่า: 0.0 – 1.0

วัดความคล้ายคลึงเชิงโครงสร้างของภาพ โดยคำนึงถึง ความสว่าง, ความคมชัด, และโครงสร้าง ใกล้เคียงการรับรู้ของสายตามนุษย์มากกว่า PSNR

SSIM = f(luminance, contrast, structure)
👁️
LPIPS ↓ ต่ำดีกว่า
Learned Perceptual Image Patch Similarity
ช่วงค่า: 0.0 – 1.0

วัดความแตกต่างของ Feature Map จาก Deep Neural Network (VGG/AlexNet) จำลองการรับรู้เชิงคุณภาพของมนุษย์ LPIPS ต่ำแปลว่าดูเป็นธรรมชาติและสมจริง

LPIPS = ‖φ(x̂) − φ(x)‖₂²
✨
NIQE ↓ ต่ำดีกว่า
Natural Image Quality Evaluator
No-Reference (ไม่ต้องใช้ Ground Truth)

วัดความเป็นธรรมชาติของภาพโดยเทียบกับแบบจำลองสถิติภาพธรรมชาติ (NSS Model) ยิ่งต่ำแสดงว่าภาพไม่มีสิ่งแปลกปลอม (Artifacts) และสมจริงตามธรรมชาติ

NIQE = D(v_test, v_natural)
🌟
MUSIQ ↑ สูงดีกว่า
Multi-scale Image Quality Transformer
ช่วงคะแนน: 0.0 – 100.0

โมเดล Transformer ประเมินคุณภาพความสวยงามเชิงสายตาแบบ Multi-scale Patch ทนทานต่อขนาดภาพทุกสัดส่วน ยิ่งคะแนนสูงยิ่งสะท้อนความคมชัดระดับพรีเมียม

MUSIQ Score ∈ [0, 100]
⏱️
Latency ↓ ต่ำดีกว่า
Processing Time per Image
หน่วย: ms (millisecond)

วัดความเร็วในการประมวลผลของโมเดลต่อภาพหนึ่งใบ บนฮาร์ดแวร์ RTX 3050 Ti Laptop GPU (4 GB VRAM) ค่านี้สำคัญสำหรับการนำไปใช้งานจริงแบบ Real-time

Latency = t_end − t_start (ms/image)
💬 เหตุผลที่เลือกตัวชี้วัดชุดนี้
🎯
Full-Reference Pair: PSNR + SSIM วัดความถูกต้องเชิงพิกเซลและโครงสร้างเทียบกับ Ground Truth ใช้ได้กับ Synthetic Dataset ของเรา
🧠
Perceptual Quality: LPIPS สะท้อนความสวยงามตามการรับรู้ของมนุษย์ได้ดีกว่า PSNR/SSIM โมเดล GAN มักได้ LPIPS ต่ำกว่า (ดีกว่า) แม้ PSNR จะต่ำกว่า
⚡
Practical Efficiency: Latency สำคัญสำหรับ Use Case จริง ทีมทดสอบบนฮาร์ดแวร์เดียวกัน เพื่อให้เปรียบเทียบโมเดลได้อย่างยุติธรรม

✅ ข้อสังเกตและจุดแข็งของโมเดลทีม
  • Trade-off ระหว่าง PSNR กับ Perceptual Quality: Bicubic และ Real-ESRNet (Pretrained) มีค่า PSNR/SSIM สูงสุด (23.41 / 0.7065) เพราะใช้ L1 Loss มุ่งเป้าระดับพิกเซล ภาพสมดุลและไม่มี Artifact
  • โมเดลของทีม (52k iters): ค่า MUSIQ ขยับขึ้นมาที่ 48.08 (ชนะ Bicubic ที่ได้ 35.70 อย่างชัดเจน) แสดงถึงคุณภาพเชิงสายตาและความคมชัดที่ดีขึ้นอย่างแท้จริง
  • ไม่มี GAN Hallucination: การใช้ L1 Loss ทำให้ไม่เกิดภาพหลอนหรือเส้นบิดเบี้ยวแปลกปลอม โครงสร้างของภาพคงความถูกต้องสูง
  • ความเร็วในการประมวลผล: Inference Time อยู่ที่ ~110 ms ต่อภาพ เหมาะสมกับการประยุกต์ใช้งานจริง
