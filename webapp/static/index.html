❓ ปัญหา (The Problem)

ทำไม Bicubic ไม่เพียงพอ?

ภาพถ่ายในโลกจริงมีความเสื่อมสภาพจากหลายแหล่งพร้อมกัน ทั้งการสั่นไหวของกล้อง (Motion Blur), สัญญาณรบกวนจากเซนเซอร์ (Sensor Noise), การบีบอัด JPEG (Compression Artifact) และความละเอียดต่ำจากระยะห่าง — Bicubic Interpolation ขยายภาพโดยการประมาณค่าระหว่างพิกเซล ทำให้ภาพเบลอมัวและสูญเสียรายละเอียด ไม่สามารถสร้างเนื้อหาใหม่ได้

📷 Blur & Camera Shake ⚡ Sensor Noise 🗜️ JPEG Artifacts 🔍 Resolution Loss
💡 แนวทางแก้ไข (Our Approach)

📊 ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)

วิธีวัดคุณภาพ Super-Resolution

งานวิจัยด้าน Image Restoration ใช้ตัวชี้วัดหลายมิติพร้อมกัน เพราะตัวชี้วัดแต่ละตัวสะท้อนมุมมองที่แตกต่างกัน

📐
PSNR ↑ สูงดีกว่า
Peak Signal-to-Noise Ratio
หน่วย: dB (Decibel)

วัดอัตราส่วนระหว่างสัญญาณภาพสูงสุดกับสัญญาณรบกวน โดยคำนวณจาก Mean Squared Error (MSE) ระหว่างภาพทำนายกับภาพต้นฉบับ ยิ่งสูงยิ่งหมายความว่าภาพใกล้เคียงต้นฉบับมากขึ้น

PSNR = 10 · log₁₀(MAX² / MSE)
🏗️
SSIM ↑ สูงดีกว่า
Structural Similarity Index Measure
ช่วงค่า: 0.0 – 1.0

วัดความคล้ายคลึงเชิงโครงสร้างของภาพ โดยคำนึงถึง ความสว่าง, ความคมชัด, และโครงสร้าง ใกล้เคียงการรับรู้ของสายตามนุษย์มากกว่า PSNR

SSIM = f(luminance, contrast, structure)
👁️
LPIPS ↓ ต่ำดีกว่า
Learned Perceptual Image Patch Similarity
ช่วงค่า: 0.0 – 1.0

วัดความแตกต่างของ Feature Map จาก Deep Neural Network (VGG/AlexNet) จำลองการรับรู้เชิงคุณภาพของมนุษย์ LPIPS ต่ำแปลว่าดูเป็นธรรมชาติและสมจริง

LPIPS = ‖φ(x̂) − φ(x)‖₂²
✨
NIQE ↓ ต่ำดีกว่า
Natural Image Quality Evaluator
No-Reference (ไม่ต้องใช้ Ground Truth)

วัดความเป็นธรรมชาติของภาพโดยเทียบกับแบบจำลองสถิติภาพธรรมชาติ (NSS Model) ยิ่งต่ำแสดงว่าภาพไม่มีสิ่งแปลกปลอม (Artifacts) และสมจริงตามธรรมชาติ

NIQE = D(v_test, v_natural)
🌟
MUSIQ ↑ สูงดีกว่า
Multi-scale Image Quality Transformer
ช่วงคะแนน: 0.0 – 100.0

โมเดล Transformer ประเมินคุณภาพความสวยงามเชิงสายตาแบบ Multi-scale Patch ทนทานต่อขนาดภาพทุกสัดส่วน ยิ่งคะแนนสูงยิ่งสะท้อนความคมชัดระดับพรีเมียม

MUSIQ Score ∈ [0, 100]
⏱️
Latency ↓ ต่ำดีกว่า
Processing Time per Image
หน่วย: ms (millisecond)

วัดความเร็วในการประมวลผลของโมเดลต่อภาพหนึ่งใบ บนฮาร์ดแวร์ RTX 3050 Ti Laptop GPU (4 GB VRAM) ค่านี้สำคัญสำหรับการนำไปใช้งานจริงแบบ Real-time

Latency = t_end − t_start (ms/image)
💬 เหตุผลที่เลือกตัวชี้วัดชุดนี้
🎯
Full-Reference Pair: PSNR + SSIM วัดความถูกต้องเชิงพิกเซลและโครงสร้างเทียบกับ Ground Truth ใช้ได้กับ Synthetic Dataset ของเรา
🧠
Perceptual Quality: LPIPS สะท้อนความสวยงามตามการรับรู้ของมนุษย์ได้ดีกว่า PSNR/SSIM โมเดล GAN มักได้ LPIPS ต่ำกว่า (ดีกว่า) แม้ PSNR จะต่ำกว่า
⚡
Practical Efficiency: Latency สำคัญสำหรับ Use Case จริง ทีมทดสอบบนฮาร์ดแวร์เดียวกัน เพื่อให้เปรียบเทียบโมเดลได้อย่างยุติธรรม

🔍 เจาะลึกความแตกต่างของสถาปัตยกรรม: VGG Discriminator เทียบกับ U-Net + Spectral Normalization (SN)

❌ VGG-style Discriminator (โครงสร้างเดิมของ SRGAN / ESRGAN)
  • สถาปัตยกรรม: โครงข่ายแบบเรียงลำดับ (Feed-forward Convolutional) ลึกหลายชั้น ซึ่งบีบลดขนาดภาพลงเรื่อยๆ จนเหลือตัวเลข Scalar เดียว (Real/Fake)
  • ข้อจำกัด: ตัดสินภาพจากภาพรวมทั้งใบ (Global Context) ทำให้ไม่สามารถแยกแยะความคมชัดของลวดลายเฉพาะจุด (Local Textures) ได้ละเอียดพอ
  • ผลกระทบ: เมื่อเทรนลึกมักเกิดปัญหา Unnatural Noise, การกระจายสีผิดเพี้ยน หรือเกิดสิ่งแปลกปลอมตามขอบวัตถุ (LPIPS พุ่งสูงถึง 0.2980)
✅ U-Net Discriminator + Spectral Normalization (SN) (ของ Real-ESRGAN)
  • U-Net Architecture: โครงข่ายแบบ Encoder-Decoder พร้อม Skip Connections ส่งข้อมูลระดับ Pixel-level ข้ามมารวมกัน ทำให้สามารถประเมินผลและให้ Loss Feedback ได้ทั้งระดับพิกเซลเฉพาะจุด (Local Textures) และโครงสร้างภาพรวม (Global Semantics)
  • Spectral Normalization (SN): บังคับ Lipschitz Constant ของแต่ละ Convolution Layer ให้ไม่เกิน 1 ป้องกันไม่ให้ Discriminator โอเวอร์ฟิต (Vanishing/Exploding Gradient) ระหว่างฝึกสอน
  • ผลลัพธ์: โมเดลสร้างพื้นผิวที่สมจริง ไม่เกิดลายหลอน (Overshoot ลดลงเหลือ 0.015 และ NIQE ดีขึ้นเป็น 4.631)

📐 นิยามและสูตรคณิตศาสตร์ของตัววัดประสิทธิภาพทั้งหมด (Evaluation Metrics & Formulas)

1. PSNR (Peak Signal-to-Noise Ratio) [dB] ↑
PSNR = 10 · log10(MAX_I² / MSE)
วัดอัตราส่วนกำลังสัญญาณสูงสุดต่อ Mean Squared Error (MSE) ระดับพิกเซล ยิ่งสูงยิ่งใกล้เคียงพิกเซล Ground Truth
2. SSIM (Structural Similarity Index) ↑
SSIM = (2μ_x μ_y + c1)(2σ_xy + c2) / (...)
ประเมินความคล้ายคลึงเชิงโครงสร้างผ่าน Luminance, Contrast และ Structure ช่วงคะแนน 0 ถึง 1 ยิ่งใกล้ 1 ยิ่งโครงสร้างสมบูรณ์
3. LPIPS (Learned Perceptual Similarity) ↓
d(x, x0) = Σ_l w_l ⊙ ||ŷ^l - ŷ0^l||²
วัดระยะห่างทางสายตามนุษย์โดยสกัด Deep Features (AlexNet/VGG) ยิ่งต่ำยิ่งดี ชี้ว่ามนุษย์มองแล้วรู้สึกเป็นธรรมชาติ
4. NIQE (Natural Image Quality Evaluator) ↓
D(ν1, ν2, Σ1, Σ2) = √((ν1-ν2)ᵀ Σ⁻¹ (ν1-ν2))
No-Reference IQA วัดความเบี่ยงเบนจากสถิติภาพธรรมชาติ (Natural Scene Statistics) ยิ่งต่ำยิ่งไร้ Artifact หลอก
5. MUSIQ (Multi-scale Image Quality Transformer) ↑
Score = VisionTransformer(MultiScalePatches(I))
ใช้ Vision Transformer วัดความสวยงามและ Aesthetic ของภาพหลายสเกลพร้อมกัน คะแนนเต็ม 100 ยิ่งสูงยิ่งสวยงาม
6. Overshoot Ratio (การวัดเส้นเรืองแสงหลอกตา) ↓
Overshoot = Σ max(0, |∇I_SR| - |∇I_GT|) / (Σ |∇I_GT| + ε)
ใช้ 2D Sobel Filter คำนวณขอบที่คมเกินจริง (Over-sharpening Halo) ยิ่งต่ำยิ่งดี (ขอบคมตัดเป็นธรรมชาติ ไร้เส้นวงคลื่น)

• Consumer Hardware Optimization: ในขณะที่ผู้แต่งทางการใช้ Cluster GPU 4× V100/A100 (VRAM 32GB+, batch_size 48, gt_size 256) ทีมเราได้ออกแบบ Training & Memory Pipeline ใหม่ทั้งหมดสำหรับ GPU ระดับนักศึกษา (RTX 3050 Ti 4GB VRAM) โดยออกแบบการจัดการ Memory การสตรีม Sub-image Patches และ Dynamic Inference Tiling จนรันภาพ 4K ได้โดยไม่เกิด CUDA OOM
• Two-Stage Loss Re-balancing: ปรับจูนสัดส่วน Loss จนก้าวข้าม Perception-Distortion Tradeoff ส่งผลให้โมเดล RealESRGAN_OurTeam_Improved เอาชนะโมเดลทางการ Official ได้ครบทุกมิติหลัก: PSNR 22.02 dB (vs 21.75 dB), SSIM 0.6491 (vs 0.6477), LPIPS 0.2293 (vs 0.2349), และ NIQE 4.631 (vs 4.746)
• End-to-End Interactive Web Studio: สร้างแพลตฟอร์มเว็บนำเสนอแบบโต้ตอบเต็มรูปแบบ รองรับ Live On-the-fly IQA Evaluation, Split Slider, และ Crop Inspection

✅ ข้อสังเกตและจุดแข็งของโมเดลทีม (RealESRGAN_OurTeam_Improved)
  • ประสิทธิภาพเหนือกว่าโมเดลทางการรอบด้าน: Our Team Model Improved ทำคะแนน PSNR สูงถึง 22.02 dB และ SSIM 0.6491 ชนะ Official (21.75 dB / 0.6477) พร้อมทั้งทำค่า LPIPS ได้ต่ำถึง 0.2293 (ชนะ Official 0.2349) และ NIQE 4.631 (ชนะ Official 4.746) สะท้อนถึงความสมดุลทั้งความถูกต้องของพิกเซลและความคมชัดระดับ Perceptual
  • ก้าวข้าม Perception-Distortion Tradeoff: โมเดลผ่านการปรับปรุงสัดส่วน Loss และสถาปัตยกรรม ทำให้ลดรอยแตก Artifacts โดยยังคง Texture รายละเอียดของภาพได้อย่างเป็นธรรมชาติ
  • ความเร็วในการประมวลผล: Inference Time บน GPU อยู่ที่ ~110 ms ต่อภาพ เหมาะสมกับการประยุกต์ใช้งานจริง
⚠️ ข้อจำกัดและแนวทางต่อยอด (Future Work)
  • Overshoot Ratio: ด้วยการบูสต์ความคมชัดสูง ทำให้บริเวณขอบตัดที่มีความเปรียบต่างจัดมี Overshoot Ratio อยู่ที่ ~0.175 ซึ่งสามารถปรับลดได้ด้วยการปรับน้ำหนัก Sinc filter เพิ่มเติม
  • Fine Details: รายละเอียดตัวอักษรขนาดจิ๋วหรือลายสานละเอียดมากๆ ยังต้องอาศัยการปรับปรุงชุดข้อมูล Font/OCR เฉพาะทางในอนาคต
