❓ ปัญหา (The Problem)

ทำไม Bicubic ไม่เพียงพอ?

ภาพถ่ายในโลกจริงมีความเสื่อมสภาพจากหลายแหล่งพร้อมกัน ทั้งการสั่นไหวของกล้อง (Motion Blur), สัญญาณรบกวนจากเซนเซอร์ (Sensor Noise), การบีบอัด JPEG (Compression Artifact) และความละเอียดต่ำจากระยะห่าง — Bicubic Interpolation ขยายภาพโดยการประมาณค่าระหว่างพิกเซล ทำให้ภาพเบลอมัวและสูญเสียรายละเอียด ไม่สามารถสร้างเนื้อหาใหม่ได้

📷 Blur & Camera Shake ⚡ Sensor Noise 🗜️ JPEG Artifacts 🔍 Resolution Loss
💡 แนวทางแก้ไข (Our Approach)

📊 ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)

วิธีวัดคุณภาพ Super-Resolution

งานวิจัยด้าน Image Restoration ใช้ตัวชี้วัดหลายมิติพร้อมกัน เพราะตัวชี้วัดแต่ละตัวสะท้อนมุมมองที่แตกต่างกัน

📐
PSNR ↑ สูงดีกว่า
Peak Signal-to-Noise Ratio
หน่วย: dB (Decibel)

วัดอัตราส่วนระหว่างสัญญาณภาพสูงสุดกับสัญญาณรบกวน โดยคำนวณจาก Mean Squared Error (MSE) ระหว่างภาพทำนายกับภาพต้นฉบับ ยิ่งสูงยิ่งหมายความว่าภาพใกล้เคียงต้นฉบับมากขึ้น ค่า >30 dB ถือว่าดี

PSNR = 10 · log₁₀(MAX² / MSE)
🏗️
SSIM ↑ สูงดีกว่า
Structural Similarity Index Measure
ช่วงค่า: 0.0 – 1.0

วัดความคล้ายคลึงเชิงโครงสร้างของภาพ โดยคำนึงถึง ความสว่าง (Luminance), ความคมชัด (Contrast), และโครงสร้าง (Structure) ใกล้เคียงการรับรู้ของสายตามนุษย์มากกว่า PSNR ค่า >0.9 ถือว่าดีเยี่ยม

SSIM = f(luminance, contrast, structure)
👁️
LPIPS ↓ ต่ำดีกว่า
Learned Perceptual Image Patch Similarity
ช่วงค่า: 0.0 – 1.0

วัดความแตกต่างของ Feature Map จาก Deep Neural Network (VGG/AlexNet) เพื่อจำลองการรับรู้เชิงคุณภาพของมนุษย์ LPIPS จะสูงเมื่อภาพดูแตกต่างกันตามสายตา แม้ MSE จะต่ำก็ตาม

LPIPS = ‖φ(x̂) − φ(x)‖₂²
⏱️
Inference Latency ↓ ต่ำดีกว่า
Processing Time per Image
หน่วย: ms (millisecond)

วัดความเร็วในการประมวลผลของโมเดลต่อภาพหนึ่งใบ บนฮาร์ดแวร์ RTX 3050 Ti Laptop GPU (4 GB VRAM) ค่านี้สำคัญสำหรับการนำไปใช้งานจริงในแอปพลิเคชัน เช่น Real-time Enhancement

Latency = t_end − t_start (ms/image)

💬 บทวิเคราะห์ผลการทดลอง (Analysis)
✅ จุดแข็งของโมเดลทีม
  • ได้ PSNR สูงสุด (+0.65 dB เหนือ Real-ESRGAN Official) เพราะ L1 Loss เน้นความถูกต้องเชิงพิกเซลโดยตรง
  • SSIM สูงสุด แสดงว่าโครงสร้างภาพ (โครงขอบ, เส้น) ถูกต้องแม่นยำที่สุด
  • ไม่มี GAN Hallucination (การสร้างรายละเอียดผิดๆ) ซึ่งเป็นปัญหาหลักของ GAN-based models
  • Inference เร็วกว่า Real-ESRGAN เล็กน้อย เพราะไม่มี Discriminator
⚠️ ข้อจำกัดและงานในอนาคต
  • LPIPS สูงกว่า Real-ESRGAN (0.241 vs 0.182) หมายความว่าภาพดูสมจริงน้อยกว่าเชิงการรับรู้
  • ยังเทรนไม่ครบ 45,000 iters (ปัจจุบัน 9,000) ผลยังไม่ถึงศักยภาพสูงสุด
  • ข้อความขนาดเล็กมากๆ และ Fine Pattern ซับซ้อนยังมีความผิดพลาดบ้าง
  • งานต่อไป: Fine-tune ด้วย Real-ESRGAN (เพิ่ม Discriminator) เพื่อเพิ่ม Perceptual Quality
